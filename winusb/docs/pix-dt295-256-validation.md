# PIX-DT295 256回版の連続受信と選局試験

2026-11-07 JSTに、Rev.01と申告されたPIX-DT295をWindows x64・WinUSBで試験しました。送出上限256回のmAgicVISION 0.1.1診断版を使用し、CS ND02を5分連続で受信した後、別セッションでCS ND02 → 地デジ13ch → BS01/TS0を5周、各選局6秒測定しました。初回選局を含む15回の選局が成立しました。

| 条件 | 保存TSのCC異常 | Host入力のCC関連異常 | Host入力での最終観測時刻 |
|---|---:|---:|---:|
| CS ND02・5分 | 0 | 24 | 364 ms |
| CS ND02・5回 | 各0 | 23 / 23 / 24 / 26 / 26 | 377.325 ms |
| 地デジ13ch・5回 | 各0 | 0 / 0 / 6 / 15 / 15 | 297.711 ms |
| BS01/TS0・5回 | 各0 | 各0 | 該当なし |

時刻はHostの受信処理開始を基準としたBulk完了観測時刻です。Host入力の集計にはCC jumpと同一CCで内容が変化したパケットを含みます。16本の保存TSを独立に解析し、要求TSIDが一致し、同期・TEI・形式・PAT CRC異常も0件でした。5分試験の保存TSは7,803,904パケットでした。

5分試験では約331〜364 msにHost入力の異常が集中し、その後は測定終了まで増えませんでした。切替試験でも異常はすべて378 ms以内に集中しています。開始時の具体的な欠落箇所は未特定です。測定範囲はCSの5分連続受信と15回の選局で、数時間の録画は未検証です。

両セッションでRAM・ブート領域の復元が完了しました。測定プロセスは終了し、PnP problem codeは0でした。
