# PIX-DT295 SERVICE送出上限の対照試験

2026-11-07 JSTに、Rev.01と申告されたPIX-DT295をWindows x64・WinUSBで測定しました。mAgicVISION 0.1.1の診断版を使用し、成功上限64、128、256の順で、それぞれ初期化からCS ND02・地デジ13ch・BS01/TS0を各30秒測りました。RF設定、4096試行上限、Host実行ファイル、診断応答は各条件で共通です。各イメージのresidentはbuild ID以外がバイト一致し、元のbootstrap先頭1552 bytesも一致しました。

256回版は3方式とも保存TSでCC異常0件でした。128回版は地デジの欠落を解消しましたが、CSはリング占有99%以上が続きました。256回版のCSはBulk約39 Mbpsまで増え、SERVICE開始時のリング占有中央値は約17.4%へ低下しました。

| 成功上限 | 対象 | 保存TSのCC異常 | Bulk Mbps | SERVICE開始前の占有中央値 | SERVICE所要時間 p95 |
|---:|---|---:|---:|---:|---:|
| 64 | CS ND02 | 22,310 | 19.62 | 99.97% | 12.96 ms |
| 64 | GR13 | 12,370 | 23.24 | 99.90% | 10.96 ms |
| 64 | BS01/TS0 | 0 | 17.38 | 7.71% | 14.76 ms |
| 128 | CS ND02 | 14,685 | 26.07 | 99.93% | 18.97 ms |
| 128 | GR13 | 0 | 29.95 | 13.38% | 16.96 ms |
| 128 | BS01/TS0 | 0 | 17.39 | 7.71% | 29.88 ms |
| 256 | CS ND02 | 0 | 39.01 | 17.38% | 25.97 ms |
| 256 | GR13 | 0 | 29.96 | 13.48% | 33.98 ms |
| 256 | BS01/TS0 | 0 | 17.39 | 7.52% | 44.97 ms |

占有量と試行回数の集計は受信開始基準1秒以降かつ最後のSERVICEを除いた区間です。所要時間の集計は最後のSERVICEを除いています。256回版のBSでは安定区間645回すべてで4096試行上限へ到達し、所要時間のp95は約45 msでした。保存TSのCCは0件ですが、BSの受信レートは64回版とほぼ同じです。

256回版のCSでは、Host入力にCC関連異常28件があり、すべて受信開始基準の約333〜375 msに集中していました。保存TSの測定区間では0件です。3条件とも各チャンネルの要求TSIDを確認し、同期・TEI・形式・PAT CRC異常は0件でした。各条件1回の短時間試験で、長時間受信と繰り返し選局は別途検証が必要です。

各条件で元のRAMとブート領域の復元を確認しました。測定用プロセスは終了し、PIX-DT295のPnP problem codeは0です。診断版の生成・命令モデルとx86/x64の模擬ロード・復元試験は3条件とも通過しました。

256回版でCSの5分連続受信と15回の選局を追試しました。結果は[連続受信と選局試験](pix-dt295-256-validation.md)に記録しています。
